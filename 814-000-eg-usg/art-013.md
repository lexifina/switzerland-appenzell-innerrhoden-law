# Art. 13 Annahmepflicht und Zuweisungsrecht
1 Das Departement kann Betreiber von Abfallanlagen dazu verpflichten, die für die Anlage bewilligten Abfälle aus einem bestimmten Einzugsgebiet anzunehmen.
2 Inhaber von Abfällen können vom Departement zur Abgabe an eine bestimmte Abfallanlage verpflichtet werden.
