# Art. 26 Anmeldegebühren
1 Die Gebühr für die Anmeldung an die Hoch- und Niederwildjagd beträgt Fr. 25.--. Wird nur ein Patent gelöst, beträgt sie Fr. 15.--.
2 Für eine Gästebewilligung wird eine Gebühr von Fr. 100.-- je Patent erhoben.
3 Für die verspätete Jagdanmeldung wird eine Gebühr von Fr. 100.-- erhoben.
