# Art. 31 Entschädigung aufgrund von Baulinien
1 Erhebliche Nachteile, die dadurch entstehen, dass eine Baute beim Wiederaufbau auf eine im Interesse einer Strasse festgelegte Baulinie zurückversetzt werden muss, werden entschädigt. Die Behörde, welche die Baulinie erlassen hat, legt die Höhe der Entschädigung fest.
