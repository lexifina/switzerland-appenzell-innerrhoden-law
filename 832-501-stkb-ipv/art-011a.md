# Art. 11a Provisorische Verfügung
1 Personen, welche nachweisen können, dass sie für die Zeit bis zur definitiven Verfügung auf die Prämienverbilligung angewiesen sind, können beim Gesundheitsamt unter Einreichung der erforderlichen Unterlagen ein Gesuch um eine provisorische Verfügung stellen.
2 Eine allfällige Differenz zur definitiven Verfügung wird rückwirkend verrechnet.
